# Tracker

A small study tracker web app served by GitHub Pages.

This repository holds only the app's code. It contains no personal data: when opened, the page asks for a
GitHub token and loads its data from a separate private repository. Without the token it shows nothing.

- `index.html`: the whole app
- `sw.js`: lets the app open offline
- `manifest.webmanifest`, `icon-*.png`: home-screen icon
